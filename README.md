# ogham

**Coding standards that travel with the repo.** One bootstrap step vendors a
pinned standard into a project, adds a lint preset where the language has one,
and gives the reviewing agent a rubric to grade diffs against.

Ogham is a sibling of [Trellis](https://github.com/kodhama/trellis), which
carries how agents conduct themselves, and
[grove](https://github.com/kodhama/grove), which supervises their work. Ogham
carries how the code itself is written.

The first standard is pragmatic functional code with data kept apart from
behaviour: pure by default, effects named and isolated, immutable data, and no
business logic inside data structures.

**Status:** planning. The plan is in `docs/plans/`.

*Ogham* is the druids' tree alphabet, carved on standing stones; every letter
is named for a tree.
